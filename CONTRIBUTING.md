## 1. Теренска посета

Ова е најважниот придонес.

1. Отвори `submit.html` на телефон (или на [сајтот](https://karpos-igralista.netlify.app/submit.html))
2. Пополни ја формата додека си на игралиштето — трае ~10 минути
3. Додај фотографии (само опрема, никогаш деца)
4. Испрати — пријавата доаѓа до тимот за верификација

Ако претпочиташ хартија: отвори [`teren_checklist.md`](teren_checklist.md) и печати.

---

## 2. Пријави промена

Ако забележиш дека игралиште се промени (поправено, расипано, почистено):

1. Отвори го игралиштето на мапата
2. Клик на **„Пријави промена или проблем"**
3. Избери тип, додај фото + краток опис

## 3. Директно во код

### Подготовка (еднаш)

```bash
git clone https://github.com/darjanr/karpos-igralista.git
cd karpos-igralista
```

Отвори `index.html` во браузер — работи без сервер.

### Додај ново игралиште

1. Отвори `data.js`
2. Копирај го последниот запис и промени го `id` (следен слободен број, пр. `mk-karpos-012`)
3. Пополни ги сите полиња (структурата е документирана во `README.md`)
4. Фотографии: стави ги во `photos/ime-na-igraliste/` (само JPG, без HEIC)
5. Провери дека `computeRating(p)` дава очекувана вредност

### Фотографии — правила

- **Само опрема**, никогаш луѓе или деца
- Формат: JPG (не HEIC) — на iPhone: Settings → Camera → Formats → Most Compatible
- Минимум 3 фотографии по игралиште: општ изглед, подлога, детаљ на опремата
- Именување: `IMG_XXXX.jpg` (оригинално од телефон е во ред)
- Папката: `photos/ime-na-igraliste/` — мали букви, цртички наместо spaces

### Pull request

```bash
git checkout -b mk-karpos-012-novo-igraliste
git add data.js photos/
git commit -m "mk-karpos-012: Ново игралиште — Кај Студентски дом"
git push origin mk-karpos-012-novo-igraliste
```

Потоа на GitHub: **Compare & pull request** → опиши кратко (адреса, датум на посета).

## Стандарди за оценување

Користиме **визуелно набљудување** — не сертифицирана инспекција.

| Поле | Вредности |
|------|-----------|
| `condition` | `good` / `ok` / `poor` |
| `cleanliness` | `clean` / `ok` / `dirty` |
| `road_proximity` | `safe` / `moderate` / `risky` |
| `shade` | `none` / `partial` / `good` |
| `size` | `small` / `medium` / `large` |

Детали: [`playground_safety_standards.md`](playground_safety_standards.md)

---

## Правни напомени

- Ова **не е** сертифицирана безбедносна инспекција
- Никогаш не фотографирај деца
- Секоја оценка ја гледаат минимум 2 лица пред финализирање
- Опишуваме состојба — не обвинуваме одговорни
