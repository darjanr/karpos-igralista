# Игралишта Карпош

Граѓанска иницијатива за мапирање, оценување и подобрување на детските игралишта во Општина Карпош, Скопје. Парадигма: **g0v** — изградба на паралелна јавна услуга, толку корисна што институцијата на крај не може да ја игнорира.

---

## Тековна состојба

**MVP е изграден. Апликацијата работи со демо-податоци. Следен чекор: прво теренско посетување и внесување на реални податоци.**

- 14 игралишта со демо-податоци (ќе се заменат со реални)
- Мапа, детален панел, филтри, форма за поднесување, страница со статистики
- Систем за следење на промени со историја по игралиште
- Сè уште не поврзано на backend — поднесувањата одат во конзола

---

## Зошто

Општината е спора и бирократизирана. Ако чекаме на институциите, не се решава ништо. Но граѓаните плаќаат даноци и имаат право на безбедни простори за своите деца. Затоа правиме:

1. **Водич за родители** — "каде да го носам детето денеска" е примарната вредност
2. **Транспарентна документација** — набљудувачка чеклиста, не сертифицирана инспекција
3. **Тендерска отчетност** — крстосување на јавни набавки со вистинска состојба *(на чекање — види подолу)*
4. **Притисок преку видливост** — јавна мапа со проблеми. Општини не можат да се правtat дека не знаат.
5. **Следење на подобрувања** — документираме промени за да имаме доказ дека иницијативата работи

## Технички stack

- **Јазик:** чист HTML + CSS + JS — нема build чекор, нема зависности
- **Мапа:** Leaflet.js + CartoDB Positron tiles (суптилна, светла)
- **Фотографии:** loremflickr.com (демо) → реални фотографии по теренска посета
- **Хостинг:** Vercel или Netlify (бесплатно, drag-and-drop деплој)
- **Поднесувања:** Formspree (конфигурирај `YOUR_FORM_ID` во `submit.html` и `index.html`)
- **Податоци:** `data.js` — еден фајл, рачно одржуван, верзиониран со git

## Додавање / ажурирање на игралиште

### Прво теренско посетување

1. Отвори `submit.html` на телефон — пополни го додека си на игралиштето
2. Поднесувањето засега оди во конзола (console.log) — копирај го JSON-от
3. Јави му се на одговорниот за верификација и внесување во `data.js`

Или: земи белешки на хартија со `teren_checklist.md` и подоцна внеси директно.

### Директно внесување во `data.js`

Копирај еден постоечки запис и промени ги сите полиња. Структура:

```js
{
  id: 'mk-karpos-015',           // следен слободен број
  name: 'Название на игралиштето',
  address: 'Адреса',
  neighborhood: 'Карпош 1',      // за статистики по населба
  lat: 41.9978, lon: 21.4118,    // GPS (decimal degrees)
  condition: 'good',             // 'good' | 'ok' | 'poor'
  cleanliness: 'clean',          // 'clean' | 'ok' | 'dirty'
  safety_issues: [],             // [] или ['опис на проблем (EN 1176-1 §X.X)']
  rating_reason: 'Текст...',
  road_proximity: 'safe',        // 'safe' | 'moderate' | 'risky'
  road_note: 'Текст...',
  age_range: ['toddler', 'school'], // 'toddler' (0-3) | 'school' (3-12)
  size: 'medium',                // 'small' | 'medium' | 'large'
  shade: 'partial',              // 'none' | 'partial' | 'good'
  benches: 2,
  water_nearby: false,
  toilet_nearby: false,
  store_nearby: true,
  lighting: false,
  crowdedness: 'moderate',       // 'quiet' | 'moderate' | 'busy'
  surface: { type: 'гумирана подлога', cond: 'good', lbl: 'добра' },
  equipment: [
    { t: 'Лулашки', n: 4, c: 4 },  // type, count, condition 1-5
  ],
  notes: 'Слободни белешки.',
  tender: null,                  // или { yr, amt, scope, res, resType: 'ok'|'bad' }
  assessed: '2025-06-01',        // датум на посетата (YYYY-MM-DD)
  locks: [10, 11, 12],           // loremflickr lock броеви (замени со реални URL-ови)
  history: [],                   // [] за нова оценка; додај при промена (види подолу)
}
```

### Замена на демо фотографии со реални

Во моментов `locks` се броеви за loremflickr. Кога ќе имаш реални фотографии:
- Хостирај ги (Google Drive јавен линк, Cloudinary, или директно во репото ако се мали)
- Замени го `locks` полето со `photos: ['url1', 'url2', ...]`
- Ажурирај ги функциите `ph()` и `openPanel()` во `index.html` соодветно

## Следење на промени (change log)

Ова е главниот доказ дека иницијативата прави разлика.

**Кога игралиште се подобрува:**

1. Пред да го ажурираш записот, додај ја старата состојба во `history[]`:

```js
history: [
  {
    date: '2025-05-09',          // датум на СТАРАТА оценка
    condition: 'poor',
    cleanliness: 'dirty',
    note: 'Скршен тобоган. Пријавено до општини 09.05.2025.'
  },
],
```

2. Потоа ажурирај ги `condition`, `cleanliness`, `assessed`, `safety_issues` на тековната состојба
3. Commit со датум и опис: `git commit -m "mk-karpos-003: poor → good (поправен тобоган, јун 2025)"`

**Резултат:** `index.html` прикажува временска линија во деталниот панел. `stats.html` го брои бројот на документирани подобрувања — тоа е бројката со која се оди кај општини и медиуми.

### Тендерска отчетност — зошто е на пауза

Тековните тендерски податоци во `data.js` се **демо**. Лажни бројки за отчетност се поопасни од никакви бројки.

**Опции за реални податоци:**
- Рачна претрага на [e-nabavki.gov.mk](https://e-nabavki.gov.mk) — пребарај "Општина Карпош" + "игралишта"
- Контакт со советниците од зелената фракција во советот — побарај историски извештаи
- Барање по Законот за слободен пристап до информации (ЗСПИ)

Кога ќе се добијат реални бројки, тендерскиот блок во `data.js` и `stats.html` е готов да ги прими.
